# SGP - Sistema de Gerenciamento de Projetos 🚀

O **SGP** é uma solução customizada desenvolvida para otimizar fluxos internos e automatizar o gerenciamento de tarefas. Diferente de ferramentas genéricas, este sistema foi projetado para atender necessidades reais de organização e acompanhamento de prazos em um ambiente corporativo.

## 🌐 Visualização Online
O projeto está hospedado e pode ser acessado e testado através do link abaixo:
🔗 **[Acesse o SGP aqui](https://controle-producao-pied.vercel.app/login.html)**

## 📌 O Problema que este Projeto Resolve
Muitas equipes sofrem com a dispersão de informações e a falta de visibilidade sobre o progresso de tarefas críticas. O SGP centraliza essas demandas, permitindo uma gestão visual e eficiente, eliminando gargalos de comunicação e garantindo que os prazos sejam cumpridos.

## 🛠️ Tecnologias e Ferramentas
* **Backend:** [Node.js](https://nodejs.org/) com o framework **Express**.
* **Frontend:** HTML5, CSS3 e **JavaScript (Vanilla)** para uma interface leve e responsiva.
* **Hospedagem:** Vercel (ou plataforma utilizada).
* **Versionamento:** Git & GitHub.

## ✨ Funcionalidades Principais
* **Gestão de Ciclo de Vida:** Criação, edição e finalização de tarefas.
* **Painel de Controle:** Dashboard para visualização rápida do status dos projetos (Pendentes, Em Andamento, Concluídos).
* **Priorização Inteligente:** Categorização de tarefas por nível de urgência.
* **Interface Responsiva:** Acessível tanto em desktops quanto em dispositivos móveis.

## 🧠 Lições Aprendidas & Desafios Técnicos
Durante o desenvolvimento deste sistema, os principais focos foram:
1.  **Arquitetura Limpa:** Organização do backend em rotas e controladores para facilitar a manutenção.
2.  **Lógica de Negócio:** Tradução de necessidades operacionais de uma empresa em funcionalidades de software.
3.  **Manipulação de DOM:** Uso de JavaScript puro para criar uma experiência de usuário dinâmica sem a necessidade de frameworks pesados no frontend.
